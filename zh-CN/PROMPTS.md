# 任务提示词入口

按实际使用的客户端选择提示词：

- [Codex 任务提示词](codex/examples/PROMPTS.md)，使用 `$rd-*` 调用。
- [Claude Code 任务提示词](claude/examples/PROMPTS.md)，使用本地 `/rd-*` 或账户同步 `/anthropic-skills:rd-*` 调用。
- [英文提示词入口](../PROMPTS.md)。

账户级定制见 [ChatGPT 网页版专用指令](docs/personalized-custom-instructions.md)或 [Instructions for Claude（仅英文版）](../docs/claude-personalized-instructions.md)。账户指令与本地代理任务提示词的安装位置和权限作用域分别适用。
